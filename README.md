# Sense-appen — demo

Klikbar demo af Sense-appen: https://publicsoda-png.github.io/sense-app-demo/

- Kører helt i browseren. Data gemmes kun på din egen enhed, og der trækkes ingen penge.
- Demo-login: `demo@sense.test` / `demo1234` (eller opret din egen konto). "Nulstil demo" ligger under Profil.
- **iPhone:** Safari → Del → Føj til hjemmeskærm. **Android:** Chrome → ⋮ → Installer app.

Dette repo indeholder kun den byggede web-app. Det opdateres med `pnpm deploy:demo` fra kildekoden.
